# kelingking

Assets for the standalone build of Kelingking, a three.js scroll descent of Kelingking Beach,
Nusa Penida. The page loads them from jsDelivr, pinned to a tag: `kelingking-v2` / `1.11.0` for the
final version of the scene (v34), `kelingking-v1` / `1.10.0` for v11 and v12 (only the terrain changed
between them), and `kelingking-v3` / `1.15.0` for the landing page around it, which added `hero/`.

- `textures/`: ground and path textures from Poly Haven, CC0 1.0, resized and repacked. The
  list is in `textures/CREDITS.md`.
- `terrain/terrain-1024.bin`: the terrain, plants and water masks, baked (gzip). The coastline
  and the path come from OpenStreetMap data, © OpenStreetMap contributors, available under the
  Open Database License (https://www.openstreetmap.org/copyright).
- `hero/`: the pictures the landing page's postcards lie on (sand, a cliff path, shallow water,
  sand with footprints, the sea's edge and a map of it for the page's wave) and its palm leaf.
  Generated by Sam Aing for this page.
