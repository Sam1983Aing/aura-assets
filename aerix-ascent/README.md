# AERIX Ascent assets

Public assets for the approved V4.17.1 AERIX product concept.
The standalone HTML contains all page code, styles and runtime libraries. It loads
only these model segments, images, fonts and the Draco decoder over HTTPS.

The six model segments reconstruct the original 137611648-byte GLB exactly.
SHA-256: `90ed965cea1f6e9469772c0b2ecd19f21cbd1c072ad551d1b424ac31bbb3de35`
No geometry, textures, materials or animation tracks were reduced.

The existing folders in aura-assets are independent and remain unchanged.
Third-party license notices are included with the corresponding assets.
